# Keybindings
### Quick cheatsheet on all of my Keybindings. This list is subject to change!
### Created by: Ryan M, This file was produced on the fly by Claude.

> `$mainmod` = Super key

---

## Window Management

| Keybind               | Action                      |
| -----------------------| -----------------------------|
| `Super + W`           | Close focused window        |
| `Alt + F4`            | Close focused window        |
| `Super + Q`           | Toggle window float         |
| `Shift + F11`         | Toggle fullscreen           |
| `Super + L`           | Pin active window to screen |
| `Super + Shift + L`   | Lock user session           |
| `Super + Delete`      | Logout launcher             |
| `Ctrl + Alt + Delete` | Logout screen               |
| `Super + Ctrl_R`      | Hide Waybar                 |

## Window Resizing

Hold to repeat.

| Keybind | Action |
|---------|--------|
| `Super + Ctrl + Shift + Right` | Resize window right |
| `Super + Ctrl + Shift + Left` | Resize window left |
| `Super + Ctrl + Shift + Up` | Resize window up |
| `Super + Ctrl + Shift + Down` | Resize window down |

## Workspaces

| Keybind                | Action                                 |
| ------------------------| ----------------------------------------|
| `Super + 1-0`          | Switch to workspace 1–10               |
| `Super + Shift + 1-0`  | Move window to workspace 1–10 (follow) |
| `Super + Alt + 1-0`    | Move window to workspace 1–10 (silent) |
| `Super + Ctrl + Right` | Next workspace                         |
| `Super + Ctrl + Left`  | Previous workspace                     |
| `Super + Ctrl + Down`  | Next empty workspace                   |
| `Super + Ctrl + Up`    | Last active workspace                  |
| `Super + T`            | Toggle split direction (top/side)      |
